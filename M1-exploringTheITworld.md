# 📝 Investigación: Explorando el mundo TI

La gran diferencia que encontré en la investigación de perfiles no es solo que el Senior "sabe más código", sino que el Senior entiende el impacto del código en el negocio.

**El Junior pregunta:** "¿Cómo hago que este bucle for funcione?"

**El Senior pregunta:** "¿Es necesario este bucle o podemos optimizar la consulta a la base de datos para no saturar el servidor?"

## 🟢 Nivel 1: Python Developer Junior

Este es el rol de entrada. Las empresas buscan potencial, capacidad de aprendizaje y buena lógica, más que un conocimiento enciclopédico.

### **🛠️ Herramientas que manejan:**

**Lenguajes:** Python (sólido en sintaxis y estructuras de datos), SQL básico.

**Frameworks Web:** Flask, FastAPI o Django (generalmente saben usar uno bien).

**Control de Versiones:** Git (conocimiento de commit, push, pull, branch).

**Entorno:** Uso básico de terminal/Linux, entornos virtuales (venv, conda).

**Bases de Datos:** Realizar consultas simples (SELECT, INSERT) en PostgreSQL o MySQL.

**Otras:** Postman (para probar APIs), Jira/Trello (para ver sus tareas).

### **📋 Actividades generales:**

**Corrección de Bugs:** Solucionar errores específicos reportados en el código existente.

**Desarrollo de Funcionalidades Pequeñas:** Crear endpoints simples para una API o scripts de automatización bajo supervisión.

**Writing Tests:** Escribir pruebas unitarias para asegurar que su código no rompa nada.

**Code Review (Receptor):** Recibir feedback de desarrolladores más experimentados y corregir su código en base a ello.

**Documentación:** Mantener actualizados los README y la documentación técnica de sus tareas.

### **🏢 Empresas típicas:**

**Consultoras y Software Factories:** (Ej. Globant, Indra, Tata). Suelen tener "Bootcamps" o programas de semilleros.

**Startups en crecimiento:** (Ej. Fintual, Buk). Buscan gente con mucha "hambre" de aprender.

## 🔴 Nivel 2: Python Developer Senior

Aquí el juego cambia. No se trata solo de escribir código, sino de tomar decisiones de arquitectura, escalabilidad y negocio. Se espera autonomía total.

### **🛠️ Herramientas que manejan:**

**Arquitectura:** Microservicios, Serverless, patrones de diseño (Singleton, Factory, etc.).

**Cloud & DevOps:** AWS/Azure/GCP a nivel profundo (EC2, Lambda, S3), Docker, Kubernetes, CI/CD pipelines (GitHub Actions, Jenkins).

**Bases de Datos Avanzadas:** Optimización de queries, diseño de esquemas, NoSQL (MongoDB, Redis), Sharding.

**Calidad de Código:** Herramientas de análisis estático (SonarQube), TDD (Test Driven Development).

**Observabilidad:** Datadog, New Relic, Prometheus (saben cómo monitorear la aplicación en vivo).

### **📋 Actividades generales:**

**Diseño de Sistemas:** Definir qué tecnologías se usarán para un proyecto nuevo (ej. "¿Usamos Django o FastAPI? ¿SQL o NoSQL?").

**Mentoria:** Guiar a los Juniors y Semi-seniors, desbloquear sus problemas técnicos.

**Code Review (Emisor):** Revisar el código del equipo para asegurar calidad, seguridad y rendimiento.

**Resolución de Incidentes Críticos:** Si el servidor se cae a las 3 AM, el Senior sabe cómo levantarlo y encontrar la causa raíz.

**Comunicación con Negocio:** Traducir requerimientos comerciales ("Necesitamos vender más rápido") a soluciones técnicas ("Implementemos un caché con Redis").

### **🏢 Empresas típicas:**

**Big Tech & Unicornios:** (Ej. Mercado Libre, Rappi, NotCo, Uber, Google). Requieren Seniors para manejar sistemas con millones de usuarios.

**Bancos y Fintechs Consolidadas:** Donde la seguridad y la robustez del código son críticas.
